AVD in Kubernetes

  • netadopt
    Reads an AVD repository, reports what it holds, and writes it as Kubernetes objects — and a lab of its switches.
    PyPI Source
  • function-avd
    Runs AVD in Kubernetes: builds each switch's configuration from those objects, pushes it over eAPI, and pushes it again after a change by hand.
    Source

Run a lab

  • netclab-chart
    Helm chart that runs routers, hosts and traffic generators as pods — cEOS, SR Linux, FRR, ixia-c — cabled together with Multus. You describe a topology; it becomes a running network. netclab, on PyPI, brings the cluster and the lab up in one command.
    Helm repository PyPI Source

Configure devices

  • netclab-xp
    Crossplane packages that turn router configuration into Kubernetes resources: configuration-eos for Arista EOS, from a single interface up to a whole router, over RESTCONF, JSON-RPC or eAPI, and configuration-iosxe for Cisco IOS XE over RESTCONF.
    Documentation Source
  • function-eapi
    Turns EOS CLI configuration into resources applied to devices over JSON-RPC.
    Source
